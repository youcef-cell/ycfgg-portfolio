# Portfolio Project

This project is a static personal portfolio site for a creative studio / designer.

## Stack
- HTML
- CSS
- JavaScript
- No build step required

## Project structure
- `index.html` — page structure and social links/email
- `styles.css` — typography, layout, responsiveness, mobile nav
- `script.js` — interactive carousel / lightbox / menu logic
- `images/` — static images
- `videos/` — video files

## Local preview
From the project root, run:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

- Keep the layout editorial, dark, high-contrast, and luxury/creative in tone.
